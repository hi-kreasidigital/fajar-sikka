1. Cara kerja

Website ini hanya memakai tiga layanan: Airtable (tempat menulis konten), GitHub (menyimpan kode, membangun, dan menampilkan website — gratis), dan domain (opsional, bisa dipasang kapan saja).

Tulis di Airtable→GitHub membangun website
otomatis 06:07 & 18:07 WITA→Website tayang

Perubahan di Airtable tidak langsung muncul. Website diperbarui otomatis dua kali sehari. Kalau ingin segera tampil, tekan tombol Run workflow (lihat cara menerbitkan manual) — sekitar 2–3 menit kemudian website sudah berubah.

2. Pemasangan pertama (sekali saja)

Butuh waktu sekitar 20 menit. Anda perlu akun GitHub (gratis) dan akses ke base Airtable Fajar Sikka.

  1. Buat repositori di GitHub Masuk ke github.com/new. Isi nama, misalnya fajar-sikka, pilih Public (wajib untuk hosting gratis), lalu klik Create repository.
  2. Unggah semua berkas website Di halaman repositori baru, klik uploading an existing file, lalu seret seluruh isi folder website ini (bukan file ZIP-nya). Klik Commit changes.
    Pastikan folder .github ikut terunggah. Folder ini tersembunyi di sebagian komputer. Di Mac tekan Cmd+Shift+. untuk menampilkannya; di Windows aktifkan View → Hidden items. Jika ragu, pakai aplikasi GitHub Desktop.
  3. Buat token Airtable Buka airtable.com/create/tokens → Create token. Beri nama Website Fajar Sikka. Pada Scopes tambahkan data.records:read saja. Pada Access pilih base Fajar Sikka. Klik Create token dan salin tokennya (diawali pat).
    Token hanya bisa membaca. Jangan bagikan token di chat atau dokumen publik.
  4. Simpan token di GitHub Di repositori: Settings → Secrets and variables → Actions → New repository secret. Name: AIRTABLE_TOKEN, Secret: tempel token tadi → Add secret.
  5. Aktifkan GitHub Pages Settings → Pages → pada Build and deployment, bagian Source pilih GitHub Actions.
  6. Terbitkan pertama kali Buka tab Actions (jika diminta, klik tombol hijau untuk mengaktifkan workflow) → pilih Bangun & terbitkan website di kiri → Run workflow → Run workflow. Tunggu sampai tanda centang hijau (±3 menit).
  7. Buka website Anda Alamatnya: https://nama-akun-github.github.io/fajar-sikka/ (juga tertera di Settings → Pages).
    Selesai! Mulai sekarang website diperbarui otomatis dua kali sehari dari Airtable.

Menulis artikel

  1. Tambah baris di tabel Artikel, isi Judul, Ringkasan (1–2 kalimat, muncul di Google), dan Isi.
  2. Unggah Foto Sampul dan isi Keterangan Foto Sampul (penting untuk Google dan pembaca tunanetra).
  3. Untuk foto di tengah tulisan, unggah ke Foto Artikel lalu ketik [foto:1], [foto:2], dst. pada baris tersendiri di Isi.
  4. Centang Izin Foto hanya jika semua orang di foto setuju.
  5. Ingin versi Inggris? Isi Judul EN dan Isi EN. Tanpa keduanya, artikel hanya tampil di versi Indonesia.
  6. Ubah Status menjadi Terbit. Lihat baris Contoh artikel (berstatus Draf) sebagai contoh format.
Kolom Slug adalah bagian alamat halaman (mis. /kabar/pelatihan-tenun/). Boleh dikosongkan — akan dibuat otomatis dari judul. Setelah terbit, jangan diubah agar tautan yang sudah dibagikan tidak rusak.

Donasi

Di tabel Pengaturan, isi rekening_bank, rekening_nomor, dan rekening_nama. Selama kosong, halaman Dukung Kami otomatis menampilkan kontak email & WhatsApp saja.

Tips foto

  • Kecilkan foto ke lebar maksimal ±2000 piksel sebelum diunggah. Kuota Airtable gratis hanya 1 GB per base.
  • Gunakan JPG atau PNG. Foto iPhone format HEIC tidak bisa diproses — ubah ke JPG dulu (di iPhone: Settings → Camera → Formats → Most Compatible).
  • Website otomatis mengubah foto menjadi format WebP yang ringan untuk jaringan seluler.

4. Memasang domain sendiri

Website sudah bisa dipakai dengan alamat github.io. Kapan pun domain sudah dibeli (mis. fajarsikka.org), ikuti langkah di bawah. Tidak perlu mengubah kode apa pun — website mendeteksi alamat barunya sendiri.

Pembantu pengaturan domain — isi kolom di bawah, langkah-langkahnya akan disesuaikan otomatis.

  1. Atur DNS di tempat membeli domain Masuk ke panel penjual domain (Niagahoster, Rumahweb, Namecheap, Cloudflare, dll.) → menu DNS / Kelola DNS. Hapus catatan A/AAAA lama untuk @ jika ada, lalu tambahkan catatan pada tabel di atas.
  2. Pasang domain di GitHub Repositori → Settings → Pages → Custom domain → ketik domain Anda → Save. Tunggu pemeriksaan DNS berhasil (bisa beberapa menit hingga 24 jam).
  3. Aktifkan HTTPS Setelah pemeriksaan berhasil, centang Enforce HTTPS di halaman yang sama.
  4. Bangun ulang website Tab Actions → Bangun & terbitkan website → Run workflow. Seluruh tautan, sitemap, dan data Google otomatis memakai domain baru.
  5. Daftarkan ke Google Buka Google Search Console, tambahkan domain, lalu kirim sitemap: https://domain-anda/sitemap.xml.
Opsional (lebih aman): verifikasi domain di akun GitHub (profil → Settings → Pages → Add a domain) agar domain tidak bisa dipakai orang lain jika suatu saat website dimatikan.
Untuk teknisi: jika ingin memaksa alamat tertentu (mis. hosting di tempat lain), isi "alamat_website" di berkas site.config.json. Biarkan kosong untuk deteksi otomatis.

5. Hal penting

  • Privasi & keamanan komunitas. Foto hanya tampil bila kolom izin dicentang. Periksa juga isi tulisan: jangan menyebut nama, alamat, atau identitas anggota tanpa persetujuan.
  • Jadwal otomatis bisa berhenti. GitHub menonaktifkan jadwal otomatis pada repositori yang 60 hari tidak ada perubahan kode. GitHub akan mengirim email peringatan — cukup buka tab Actions dan klik Enable workflow, atau jalankan Run workflow sesekali.
  • Batas Airtable gratis: 1.000 baris per base, 1 GB lampiran, 1.000 panggilan API per bulan. Satu kali build memakai ±7 panggilan, jadi 2× sehari + beberapa kali manual masih aman. Airtable juga memiliki program diskon untuk organisasi nirlaba.
  • Kalau Airtable bermasalah, website yang sudah tayang tetap berjalan normal — build berikutnya saja yang tertunda.
